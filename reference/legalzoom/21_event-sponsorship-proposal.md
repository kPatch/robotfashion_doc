# LegalZoom — Event Sponsorship Proposal (template wording)

Source: https://www.legalzoom.com/templates/t/event-sponsorship-proposal
**Not a legal agreement** — a sponsor-facing pitch deck. Structure: Overview · About Us · Mission/Vision · Team · Event (date, objective, attendee profile, footfall) · Event Schedule table · **Sponsorship Benefits** list · **Sponsorship Programs** tier table (Type / Perks / Price incl. tax) · light T&Cs (relationship = sponsor/organizer only; payment N days before event; **"a Sponsorship Contract will be sent" if the sponsor is on board**; use of sponsor logos with approval; representative optional; term ends at event completion) · signatures.

**Verdict vs our draft:** Different document and different counterparty (this is RFS→**sponsor**, not RFS→**institution**). No clauses to import into the institution agreement. Useful only as a **template for RFS's sponsor-facing package** if/when RFS solicits corporate sponsors. Note the sensible sequence it models: **proposal → signed sponsorship contract** (the actual contract would be the Sponsorship Agreement, doc #01). Keep sponsor materials separate from the institution agreement.
