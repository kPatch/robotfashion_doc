## Maintaining this index

Keep clarifications within the current drafting round in the current version when requested. When establishing a new review or distribution baseline, add the next version folder under that document. Record the date/time and changes in VERSION.txt, and update its row above. Keep earlier baselines intact. Do not copy unchanged agreements into new version folders.

When sending documents to an institution, preserve a separate dated package recording the exact document versions and any institution-specific changes sent. This working index does not record transmission or execution.
