# LegalZoom Template Download Checklist

Created: 2026-07-12

Use this as the download list for LegalZoom. Download `.docx` versions if LegalZoom offers them; otherwise download PDF exports. Dummy form answers are fine as long as they expose the full template wording.

## Dummy form guidance

Use neutral placeholders when LegalZoom requires form answers:

- Organizer: `Robot Fashion Initiative`
- Institution: `Participating Institution`
- Event: `International Robot Fashion Show`
- Event location: `New York, New York`
- Event date: `Fall 2026`
- Funding amount: `USD $10,000`
- Participant: `Selected Student`
- Media use: `promotion, documentation, press, sponsor materials, livestream, archival, and educational use`
- Governing law: use `New York` for event-facing templates unless the form requires another state for a specific reason.

Do not enter real student names, passport details, bank details, SSNs, or private addresses in dummy forms.
